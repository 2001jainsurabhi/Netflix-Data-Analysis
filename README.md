# Netflix Data Analysis using Python

## Overview
This project analyzes the Netflix dataset to uncover insights about content trends, genres, countries, and release years.  
Using Python libraries like **Pandas**, **Matplotlib**, and **Seaborn**, we explore how Netflix's catalog has evolved over time.

---

## Tools & Libraries
- Python (Google Colab)
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## Key Insights
- Growth of Netflix content over the years   
- Distribution of movies vs TV shows   
- Top genres and countries contributing to Netflix's library   
- Most frequent directors, actors, and release patterns  
- Trends in content ratings and maturity levels  

---

## Files
- `Netflix_Data_Analysis.ipynb` → Main Python notebook  
- `netflix_titles.csv` → Dataset from Kaggle  

---

## How to Run
1. Open the notebook in **Google Colab** or **Jupyter Notebook**  
2. Upload the dataset in the same directory  
3. Run all cells to generate analysis and visualizations
